# Data and code availability

The source code, reference mesh dataset, pretrained models, and numerical results supporting this study are publicly available at https://github.com/JingyiZeng-USTC/edge-crack-learning-meshing.

The repository includes the original 200-mesh split, straight and curved test-case definitions, and per-case evaluation metrics. Complete generated mesh and displacement/stress arrays can be recreated using the scripts. Software is licensed under MIT; author-owned data and model parameters are licensed under CC BY 4.0. See `CITATION.cff` for citation metadata.
